Original game

Garden Match is an original casual puzzle game created for this project. The game code, layout, copy, progression, badge system, and CSS-drawn tile artwork are custom-made for Garden Match.

Artwork

The playable garden tiles are drawn with original CSS shapes and gradients. They do not use copied image files, downloaded icon packs, or third-party game art.

Audio

Garden Match uses simple browser-generated tones. It does not include copied music, sound effects, or audio samples.
